# Bin Daddy Util

An internal web utility for managing service zones, customer records, and operational notes for the Bin Daddy team.

## Overview

Bin Daddy Util is a business-focused operations platform built to help authenticated team members manage customers across service zones efficiently. The application centralizes client information, enables note tracking, and streamlines customer management through automated geocoding and bulk client upload systems.

Designed for internal use, the platform improves organization, reduces manual data entry, and helps teams quickly access customer-related information in the field or office.
